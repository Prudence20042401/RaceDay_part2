# /docs folder

Put the Part 1 planning documents in this folder (the lecturer checks for them):

- ERD image (PNG or PDF)
- Endpoint plan (PDF or Markdown) - the Part 1 version
- SQL script (`.sql`)
- `ci-build-success.png` - screenshot of a green GitHub Actions run (Part 2)

`Part2-implemented-endpoints.md` lists what the Part 2 API actually exposes. Compare it with your Part 1
endpoint plan and either update the plan or explain any difference in the README.
